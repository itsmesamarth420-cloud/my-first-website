How I'm Learning

I'm taking a build-first approach. Instead of trying to learn everything before making something, I'm building small projects and learning the concepts required to improve them.

So far, I've worked with HTML for structure, CSS for design and JavaScript for interaction. I'm also learning how Git and GitHub fit into the development workflow.

The goal isn't simply to learn how to write code. It's to understand how the different pieces of the web fit together.
